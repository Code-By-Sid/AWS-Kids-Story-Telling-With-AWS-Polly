# 📚 AI Kid Story Telling using Amazon Polly

## 📌 Project Overview

AI Kid Story Telling is a serverless AWS application that allows teachers to upload children's stories in text format through a web application. The uploaded story is stored in Amazon S3, converted into natural speech using Amazon Polly, and the generated MP3 is stored in another S3 bucket. Story details and metadata are then saved in Amazon DynamoDB and displayed on the website along with an audio player.

This project demonstrates how AWS AI services can be integrated to build an interactive storytelling platform for children.

---

# 🚀 Features

* Upload stories in `.txt` format
* Store story files in Amazon S3
* Convert story text into speech using Amazon Polly
* Generate MP3 audio automatically
* Store MP3 files in Amazon S3
* Save story metadata in Amazon DynamoDB
* Display uploaded stories on the website
* Play generated audio directly from the browser
* Responsive Flask web application

# 🔄 Project Workflow

1. Teacher uploads a `.txt` story file through the website.
2. Flask sends the story to API Gateway.
3. API Gateway invokes the Lambda function.
4. Lambda uploads the story to the S3 Story Text Bucket.
5. Amazon Polly converts the story into speech.
6. Lambda uploads the generated MP3 to the S3 Audio Bucket.
7. Story metadata is stored in DynamoDB.
8. Flask retrieves all stories and displays them on the website.
9. Users can read the story and listen to the generated narration.

# 📡 API Endpoints

## Upload Story

**POST**

```text
/upload
```

### Request

```json
{
  "filename": "lion_story.txt",
  "story": "Once upon a time there was a brave lion..."
}
```

### Response

```json
{
  "message": "Story Uploaded Successfully",
  "storyURL": "...",
  "audioURL": "...",
  "wordCount": 168,
  "readingTime": "0.84 Minutes"
}
```

---

## Get Stories

**GET**

```text
/stories
```

### Response

```json
{
  "stories": [
    {
      "storyName": "lion_story.txt",
      "storyText": "Once upon a time...",
      "storyURL": "...",
      "audioURL": "...",
      "voice": "Joanna",
      "language": "en-US",
      "wordCount": 168,
      "characterCount": 970,
      "readingTime": "0.84 Minutes",
      "timestamp": "2026-07-16 10:30:15"
    }
  ]
}
```

# 💾 DynamoDB Attributes

| Attribute      | Description              |
| -------------- | ------------------------ |
| StoryId        | Unique Story ID          |
| StoryName      | Uploaded Story File Name |
| StoryText      | Complete Story Content   |
| StoryURL       | Story File S3 URL        |
| AudioURL       | Generated MP3 URL        |
| Voice          | Amazon Polly Voice       |
| Language       | Language Code            |
| WordCount      | Number of Words          |
| CharacterCount | Number of Characters     |
| ReadingTime    | Estimated Reading Time   |
| Timestamp      | Upload Date & Time       |
